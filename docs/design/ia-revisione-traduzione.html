B · Aggiungi un account: scelta del fornitore

Aggiungi un account IA

Gli abbonamenti alle chat (Claude Pro, ChatGPT Plus, Gemini Advanced, SuperGrok…) non danno accesso alle applicazioni esterne: serve una chiave API dello stesso fornitore, che si paga a consumo e a parte. Alcuni fornitori hanno un livello gratuito; Ollama e LM Studio girano sul tuo computer.

B2 · Dopo aver scelto Claude: chiave, verifica, modello

CClaude · Anthropic
Come ottenere la chiave · circa 3 minuti · serve una carta di credito

Una chiave API è una password che permette a questa estensione di usare il tuo account Claude. Si paga a consumo: un vocale costa una frazione di centesimo.

  1. Accedi alla console
    Apri console.anthropic.com ed entra con il tuo account (anche con Google).
    cattura della pagina di accesso
  2. Aggiungi del credito
    In Settings → Billing scegli Add funds: bastano 5 $.
    cattura di Billing, con il pulsante evidenziato
  3. Crea la chiave
    In Settings → API keys premi Create Key, dalle un nome (per esempio «WhatsApp») e copiala: si vede una volta sola.
    cattura della finestra Create Key
  4. Incollala qui sotto e premi Verifica.

Guida completa, con le immagini a schermo intero ↗
