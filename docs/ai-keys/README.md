# How to get an API key

[Versione italiana](README.it.md)

For reviewing and translating voice messages the extension uses an AI account of your choice. Chat subscriptions (Claude Pro, ChatGPT Plus, Gemini Advanced, SuperGrok) do not apply to external apps: you need an API key from the same provider, billed by usage and separately. A voice message costs a fraction of a cent. Some providers have a free tier; Ollama and LM Studio run on your computer, no account needed.

Paste the key in Setup and guide → AI review and translation → Add an account.

## Claude · Anthropic

*about 3 minutes · a credit card is needed*

1. **Sign in to the console**  
   Open the Anthropic console and sign in, Google works too. It is separate from claude.ai: a Pro or Max subscription does not apply here. <https://console.anthropic.com/>

2. **Add credit**  
   In Billing choose Add funds and load the minimum, 5 $: enough for thousands of voice messages. <https://console.anthropic.com/settings/billing>

3. **Create the key**  
   In API keys press Create Key, name it (for example WhatsApp) and copy it: it is shown only once. <https://console.anthropic.com/settings/keys>

<a id="openai"></a>

## ChatGPT · OpenAI

*about 3 minutes · a credit card is needed*

1. **Sign in to the developer platform**  
   Open platform.openai.com with your ChatGPT account. A ChatGPT Plus subscription does not cover key-based usage. <https://platform.openai.com/>

2. **Add credit**  
   In Billing add a payment method and load the minimum, 5 $. <https://platform.openai.com/settings/organization/billing/overview>

3. **Create the key**  
   In API keys press Create new secret key, name it and copy it: it is shown only once. <https://platform.openai.com/api-keys>

<a id="gemini"></a>

## Gemini · Google

*about 1 minutes · no card needed · free with limits*

1. **Open Google AI Studio**  
   Sign in with your Google account and accept the terms the first time. No card needed: the free tier has a daily request limit. <https://aistudio.google.com/apikey>

2. **Create the key**  
   Press Create API key, pick or create a project and copy the key. <https://aistudio.google.com/apikey>

<a id="github"></a>

## GitHub Models · GitHub

*about 2 minutes · no card needed · free with limits*

1. **Create a GitHub token**  
   With your GitHub account open the fine-grained token page, give it a name and an expiry. <https://github.com/settings/personal-access-tokens/new>

2. **Models permission**  
   In Permissions add Models with Read-only access, then Generate token and copy it. Usage is free within daily limits. <https://github.com/settings/personal-access-tokens/new>

*about 1 minutes · no card needed*

<a id="azure"></a>

## Azure OpenAI · Microsoft

*about 10 minutes · a credit card is needed*

1. **Deploy a model**  
   In Azure AI Foundry create an Azure OpenAI resource and deploy a model, for example gpt-4.1-mini. The deployment name is the model to enter here. <https://ai.azure.com/>

2. **Endpoint and key**  
   In the resource, under Keys and Endpoint, copy KEY 1. The address to enter is the resource endpoint followed by /openai/v1. <https://portal.azure.com/>

<a id="ollama"></a>

## Ollama · Ollama

*about 10 minutes · no account*

1. **Install Ollama**  
   Download and install Ollama: it runs on your computer, the text never leaves the machine and no account is needed. <https://ollama.com/download>

2. **Download a model**  
   Pick a multilingual model that fits your computer's memory, for example qwen3 or gemma3, and download it from the Ollama app. Then press Verify below. <https://ollama.com/library>

<a id="lmstudio"></a>

## LM Studio · LM Studio

*about 10 minutes · no account*

1. **Install LM Studio and a model**  
   Install LM Studio and download a multilingual model from its search. It runs on your computer, no account needed. <https://lmstudio.ai/>

2. **Start the server**  
   In the Developer tab start the local server (port 1234), then press Verify below. <https://lmstudio.ai/docs/app/api>
