# Come ottenere una chiave API

[English version](README.md)

Per la revisione e la traduzione dei vocali l'estensione usa un account di IA scelto da te. Gli abbonamenti alle chat (Claude Pro, ChatGPT Plus, Gemini Advanced, SuperGrok) non valgono per le applicazioni esterne: serve una chiave API dello stesso fornitore, che si paga a consumo e a parte. Un vocale costa una frazione di centesimo. Alcuni fornitori hanno un livello gratuito; Ollama e LM Studio girano sul tuo computer, senza account.

La chiave si incolla in Configurazione e guida → Revisione e traduzione con l'IA → Aggiungi un account.

<a id="anthropic"></a>

## Claude · Anthropic

*circa 3 minuti · serve una carta di credito*

1. **Accedi alla console**  
   Apri la console di Anthropic ed entra con il tuo account, anche con Google. È un account diverso da quello di claude.ai: l'abbonamento Pro o Max non vale qui. <https://console.anthropic.com/>

2. **Aggiungi del credito**  
   In Billing scegli Add funds e carica il minimo, 5 $: bastano per migliaia di vocali. <https://console.anthropic.com/settings/billing>

3. **Crea la chiave**  
   In API keys premi Create Key, dalle un nome (per esempio WhatsApp) e copiala: si vede una volta sola. <https://console.anthropic.com/settings/keys>

<a id="openai"></a>

## ChatGPT · OpenAI

*circa 3 minuti · serve una carta di credito*

1. **Accedi alla piattaforma per sviluppatori**  
   Apri platform.openai.com con lo stesso account di ChatGPT. L'abbonamento ChatGPT Plus non copre l'uso tramite chiave. <https://platform.openai.com/>

2. **Aggiungi del credito**  
   In Billing aggiungi un metodo di pagamento e carica il minimo, 5 $. <https://platform.openai.com/settings/organization/billing/overview>

3. **Crea la chiave**  
   In API keys premi Create new secret key, dalle un nome e copiala: si vede una volta sola. <https://platform.openai.com/api-keys>

## Gemini · Google

*circa 1 minuti · non serve una carta · gratuito con limiti*

1. **Apri Google AI Studio**  
   Entra con il tuo account Google e accetta le condizioni la prima volta. Non serve una carta: il livello gratuito ha un limite di richieste al giorno. <https://aistudio.google.com/apikey>

2. **Crea la chiave**  
   Premi Create API key, scegli o crea un progetto e copia la chiave. <https://aistudio.google.com/apikey>

<a id="github"></a>

## GitHub Models · GitHub

*circa 2 minuti · non serve una carta · gratuito con limiti*

1. **Crea un token di GitHub**  
   Con il tuo account GitHub apri la creazione di un token fine-grained, dagli un nome e una scadenza. <https://github.com/settings/personal-access-tokens/new>

2. **Permesso Models**  
   In Permissions aggiungi Models con accesso Read-only, poi Generate token e copialo. L'uso è gratuito entro limiti giornalieri. <https://github.com/settings/personal-access-tokens/new>

## OpenRouter · OpenRouter

*circa 1 minuti · non serve una carta*

   Premi Accedi con OpenRouter: si apre la sua pagina, entri con Google, GitHub o email e autorizzi l'estensione. Nessuna chiave da copiare. <https://openrouter.ai/>

2. **Credito, se serve**  
   I modelli con :free nel nome sono gratuiti, con limiti; per gli altri carica del credito in Credits. <https://openrouter.ai/settings/credits>

<a id="azure"></a>

## Azure OpenAI · Microsoft

*circa 10 minuti · serve una carta di credito*

1. **Distribuisci un modello**  
   In Azure AI Foundry crea una risorsa Azure OpenAI e distribuisci un modello, per esempio gpt-4.1-mini. Il nome della distribuzione è il modello da indicare qui. <https://ai.azure.com/>

2. **Indirizzo e chiave**  
   Nella risorsa, in Keys and Endpoint, copia KEY 1. L'indirizzo da indicare è quello della risorsa seguito da /openai/v1. <https://portal.azure.com/>

<a id="ollama"></a>

## Ollama · Ollama

*circa 10 minuti · nessun account*

1. **Installa Ollama**  
   Scarica e installa Ollama: gira sul tuo computer, il testo non esce dalla macchina e non serve alcun account. <https://ollama.com/download>

2. **Scarica un modello**  
   Scegli un modello multilingue adatto alla memoria del computer, per esempio qwen3 o gemma3, e scaricalo dall'applicazione di Ollama. Poi premi Verifica qui sotto. <https://ollama.com/library>

<a id="lmstudio"></a>

## LM Studio · LM Studio

*circa 10 minuti · nessun account*

1. **Installa LM Studio e un modello**  
   Installa LM Studio e scarica un modello multilingue dalla sua ricerca. Gira sul tuo computer, senza account. <https://lmstudio.ai/>

2. **Avvia il server**  
   Nella scheda Developer avvia il server locale (porta 1234), poi premi Verifica qui sotto. <https://lmstudio.ai/docs/app/api>
